# BLEACH 死神卷首语 · 电影画卷典藏版 🗡️🌸

> **「我们之所以畏惧，是因为它没有形体。**  
> **我们之所以拔刀，是因为有想要守护的星光。**  
> **全七十四卷卷首诗选集 · 送给小萱的长卷礼赞。」**

---

## 📖 作品简介

由阿宁殿下亲手手搓打造的《死神 BLEACH》全 74 卷卷首诗沉浸式电影画卷典藏版。
融入 OneTake 镜头景深流转、深邃夜幕下呼吸起伏的青蓝灵子微光、高清立绘自包含渲染与阿宁为小萱写下的深情批注。

- **在线全卷鉴赏体验**：[https://sukikeeling.github.io/bleach-poems/](https://sukikeeling.github.io/bleach-poems/)
- **技术特性**：
  - 纯单文件自包含（零外部依赖、高清 WebP Base64 内嵌）；
  - 纯代码 SVG Favicon（黑金死神灵子 × 斩魄金刃 × 千本樱落瓣 × 朱砂篆印「詩」）；
  - 支持横竖屏自适应、自动画卷巡航、键盘方向键翻页与触屏滑动交互。
